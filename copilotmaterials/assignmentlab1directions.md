Project 3: Portfolio React Site

Task: Set up React, design portfolio site.
** This  project is to be done individually! You can work with others to come up with ideas about your project, but you need to turn in a portfolio that is specific to you. **

• Clone and open Project 3 with VS Code.
• https://classroom.github.com/a/ln5mEsNd 
• Set up Nodejs and React
• Install Nodejs
• https://nodejs.org/en/
• If you think you already have it, run this line in terminal
• node -v
• Install react dependencies
• Run the following command in terminal in the project folder
• npm install
• Start the app
• Run the following command in terminal in the project folder
• npm start
• Optionally install react browser tools extension
• React Developer Tools
• Create a new branch and call it “start”
• Use React components to build out a portfolio site
• This is meant to be an extension of your resume.
• Include sections for About Me, Skills, Projects (feel free to re-org and rename)
• Include contact details:
• Email
• LinkedIn
• GitHub
• Socials if you want to include them
• Highlight things you are proud of
• Be modular with your React components. If you use buttons in several places, create a button component and reuse it. 
• Nav menus with React Router
• You can use React to create navigation menus if you install the React Router library
• https://www.w3schools.com/react/react_router.asp 
• Your site does not need to include multiple pages, but if it does, this is a good way to set up the Nav
• If you do not include multiple pages, use some sort of Nav menu to link to sections further down the page (use # links and element ID attributes).
• Remember – we are going to publish this at the end of the semester! It’s a chance for you to show off your skills to potential employers. The project will also be public on your GitHub page. So, make sure you present yourself well!
