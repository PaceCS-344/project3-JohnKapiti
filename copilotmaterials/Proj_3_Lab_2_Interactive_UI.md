Project 3: Portfolio React Site

Task: Set up React, design portfolio site.

** This  project is to be done individually! You can work with others to come up with ideas about your project, but you need to turn in a portfolio that is specific to you. **

Open Project 3 with VS Code.

https://classroom.github.com/a/ln5mEsNd

Create a new branch and call it “ui”

Add interactive elements to your portfolio’s user interface. Below are some examples of interactivity you can add. Do at least 3 of these. You can substitute other features if you choose

Sticky header / headings / footer

Pin headers and/or section headings and/or a footer to the top of the screen while scrolling

Example: https://react.dev/learn (watch the top of the screen on desktop/laptop)

Animated tiles/cards for Skills and/or Projects sections

Animate some interactive behavior

Example: https://lightswind.com/components/interactive-card

Theme switcher

Light/dark/color background themes

Example: https://codepen.io/michellebarker/pen/GzzrGJ

Hamburger menu

Expandable menu (especially for mobile versions)

Example: https://codepen.io/piyushpd139/pen/jOyJgww

Read more/less expanders on sections

Accordion style expanders

Example: https://codepen.io/matthewvincent/pen/EKKeyX

Projects/skills search bar, tags

Add a search bar for filtering highlighted projects by tag (PHP, react, UI, MariaDB, etc.)

Example: https://codepen.io/jonahvsweb/pen/LGVRaX

Easter eggs

Clicking/hovering some elements reveals details or an animation

Example: https://codepen.io/tholman/pen/kxPXwX

Explain your choices in writing

Write a quick description of the 3 interactive UI pieces you added. You can do this in one of 3 ways:

git commits (if you commit each separately)

GitHub Issues for tracking your progress

The comments you add to your Classes submission

Briefly explain why you chose each feature and what tools you used to implement it.

If you add npm libraries, make sure they are added to the package.json file. This should happen automatically, but double check.

Remember – we are going to publish this at the end of the year! It’s a chance for you to show off your skills to potential employers. The project will also be public on your GitHub page. So make sure you present yourself well in this project!
